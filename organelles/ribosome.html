STRUCTURE / 06

核糖体

蛋白质装配台

核糖体由 RNA 和蛋白质组成，是合成蛋白质的重要场所。它读取 mRNA 中的信息，参与连接氨基酸。

拖动模型，查看它的另一面
01 / STRUCTURE

它长什么样？

胞质中的真核核糖体为 80S，由 60S 大亚基和 40S 小亚基组成。两者之间具有容纳 tRNA 的空间；mRNA 与小亚基相互作用，新生肽链从大亚基出口伸出。

02 / FUNCTION

它负责什么？

在翻译过程中，核糖体与其他分子协作，将 mRNA 中的信息转化为特定的氨基酸序列。

03 / COLLABORATION

它如何与其他结构协作？

核糖体可以游离在细胞质中，也可以附着于粗面内质网，参与不同蛋白质的合成。

观察笔记

这是亚基及通道关系的形态示意，不是原子结构重建。S 是沉降系数单位，因此 60S 与 40S 组成的核糖体称为 80S，而不是 100S。
